## 1. 🛣️ NHIT Digital Platform

The next-generation digital operating system for National Highways Infra Trust (NHIT). Automating green note certifications, Section 194C statutory tax deductions, multi-tier financial approvals, and direct banking UTR reconciliation across India's arterial expressway network.

- **Repository:** [HarshitNain/NHIT-Digital-Platform](https://github.com/HarshitNain/NHIT-Digital-Platform)
- **Stack:** Go, Python, TypeScript, React, PostgreSQL, Docker, Redis
- **Key Features:**
  - **Financial & Tax Automation:** Automated Section 194C statutory tax calculation and multi-tier approval chains.
  - **Banking UTR Reconciliation:** Direct host-to-host banking transaction reconciliation with 100% verified UTR matching.
  - **Distributed Resilience:** Distributed memory OTP store, secret vaults, and rate-limiting shield for enterprise security.
  - **Sub-45ms API Latency:** Highly optimized concurrent Go backend handlers with PostgreSQL indexing.
